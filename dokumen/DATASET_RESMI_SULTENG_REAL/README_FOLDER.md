# Folder Paket Dataset Resmi & Bukti Sumber Riil Sulawesi Tengah

Folder ini berisi seluruh kelengkapan data riil resmi 100% tanpa data dummy untuk presentasi akademik / pelaporan pimpinan:

### Berkas yang Tersedia di Folder Ini:
1. **[DATASET_RESMI_PARIWISATA_SULTENG_REAL.xlsx](DATASET_RESMI_PARIWISATA_SULTENG_REAL.xlsx)**:
   - Workbook Excel resmi memuat data kunjungan tahunan 2022–2025, rekap per 13 kabupaten/kota 2025, kamar hotel bintang 2021–2025, dan daftar tautan live resmi.
2. **[PRESENTASI_DATASET_RESMI_SULTENG.pptx](PRESENTASI_DATASET_RESMI_SULTENG.pptx)**:
   - File presentasi PowerPoint (16:9 widescreen) profesional dengan tema "Palet Laut Togean" siap digunakan untuk sidang skripsi/tugas akhir atau pemaparan dinas.
3. **[INDEX_PORTAL_DATASET_RESMI.html](INDEX_PORTAL_DATASET_RESMI.html)**:
   - Halaman portal HTML interaktif untuk membuka dokumen dan melihat ringkasan visual.
4. **Sub-folder [DOKUMEN_SUMBER_PDF_RESMI/](DOKUMEN_SUMBER_PDF_RESMI/)**:
   - `Rekap_Kunjungan_Wisatawan_2025_Dispar_Sulteng.pdf` (Rekap 13 Kab/Kota 2025 Dispar)
   - `Laporan_Analisis_Kunjungan_2024_Dispar_Sulteng.pdf` (Laporan Resmi 2024 Dispar)
   - `Laporan_Kunjungan_Wisatawan_2023_Dispar_Sulteng.pdf` (Laporan Resmi 2023 Dispar)
   - `Laporan_Kunjungan_Wisatawan_2022_Dispar_Sulteng.pdf` (Laporan Resmi 2022 Dispar)
   - `Statistik_Akomodasi_Hotel_Bintang_2021_2025_Kemenpar.pdf` (Publikasi Kemenpar & BPS)
   - `Definisi_Operasional_Indikator_Pariwisata_Dispar.pdf` (Juknis Definisi Indikator)

Seluruh berkas ini membuktikan bahwa data sistem Jelajah Sulteng bersumber 100% dari dokumen resmi pemerintah.
